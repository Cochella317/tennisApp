# About 
This is an application designed to help tennis players organize their training, track their matches, and monitor their improvement over time. 
The application allows users to create personalized workout plans, browse tennis drills, log match results, and reflect on their performance after each match. 
By combining training management and match analysis in one place, this application aims to help players identify strengths, improve weaknesses, and stay consistent with their development.

# Features 
## Dashboard
+ View today's workout plan
+ Quick access to key actions
+ View recent matches
+ Track weekly progress and statistics

## Drill Library
+ Browse tennis drills by category
+ View drill descriptions and instructions
+ Filter drills based on skill focus
+ Add drills to workout plans
+ Create custom drills

## Workout Planner
+ Create custom training sessions
+ Add drills to workouts
+ Organize weekly training schedules
+ Track workout completion

## Match Logger and Reflection
+ Record match details
+ Automatically determine match outcome
+ Store personal notes after each match

## Statistics
+ Track win/loss record
+ Calculate win percentage
